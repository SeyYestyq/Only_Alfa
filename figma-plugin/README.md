## Как запустить в Figma:
1. Откройте ваш файл в приложении Figma Desktop (или в вебе):
   `https://www.figma.com/design/JwsU4tdhLajO29T59zRoZc/Alfa`
2. Нажмите правой кнопкой мыши на холсте (или в верхнем меню):
   **Plugins** → **Development** → **Import plugin from manifest...**
3. Выберите файл:
   `figma-plugin/manifest.json` (или `Documents/NEW/figma-plugin/manifest.json`)
4. Нажмите **Run** (или горячие клавиши `⌥⌘P` / `Option + Command + P`).
5. Плагин за 1 секунду создаст все фреймы с автолейаутами, стилями и компонентами и центрирует холст!
