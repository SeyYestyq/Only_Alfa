### Added
- Макеты Figma (`figma-plugin/`): полная синхронизация со спецификацией плана `aaaю.md` (сквозная шапка Demo Control Bar с 5 компаниями, ИНН-лукапом, ролями Maker-Checker и тумблером Бизнес ↔ Банк; Экран 1 с 5 блоками 360°-ДНК, честной ценой овердрафта против годового кредита, демо-кнопками PDF и B2B-рассрочкой; Экран 2 с паспортом проверок, динамическим Мультибанком, витриной 4 контр-офферов и защитой ПЭП 403; Экран 3 с P&L конвейера, Waterfall 5 факторов, OpenStreetMap GeoScore/BuyerScore, блоком для Ольги Урсул и ACID Audit Trail; матрица 5 эталонных компаний BRD).
- Плагин Figma Desktop/Web (`figma-plugin/`): интеграция векторных SVG-иконок из библиотеки `Iconimate` (https://iconimate.app/) — нативная геометрия 24×24, галерея токенов-иконок во Фрейме 0, векторные бейджи для всех карточек и кнопок Экранов 1–3 и матрицы демо-профилей.
- Плагин Figma Desktop/Web (`figma-plugin/`): автоматическая генерация актуального дизайна «Only_Alfa: Умный кредитный кабинет» — Дизайн-система (токены, цвета Альфа-Банка, 5 коридоров BRD v3.0), Экран 1 (360° дашборд, ДНК, прогноз кассы 60 дней, факторинг, транзакции, поиск), Экран 2 (заявка, паспорт заемщика, Мультибанк, контр-офферы, ПЭП), Экран 3 (рентген инспектора, P&L банка, Waterfall скоринга, гео-аналитика, Audit Trail), матрица 5 демо-профилей BRD.
- Экспериментальная ветка `тестовая-реализация`: UI-апгрейд по аудиту GitHub-репозиториев — `recharts` (прогноз кассы 60 дней + Waterfall), `zustand` (Demo Control Bar), `react-dropzone` + `lucide-react` (PDF-зона), `react-leaflet` с офлайн SVG-фолбэком (GeoMap), `openapi-typescript` → `frontend/src/types/api.d.ts`.
- Checkpoint 1 MVP: FastAPI (11 эндпоинтов ТЗ), дискретный RiskScore + Decision Engine, seed 5 профилей (815/610/760/495/0), Smart Search, PDF-парсер, SPA (Demo Control Bar, Экраны 1–2, задел Экрана 3).
- `docker-compose.yml` (postgres:16-alpine + backend + frontend), `.env.example`, Dockerfiles, корневой `openapi.yaml`.
- Автотесты pytest: конвейер, скоринг, поиск, PDF, коды 403/409/422.
- Backend: слоистая структура `api → services`, `services → domain` и `services → repositories`, 9 таблиц (компании, пользователи, ДНК, транзакции, заявки, проверки, события, каталог, новости), идемпотентный сидер и 15 бизнес-маршрутов + `/health`.
- Domain: дискретный RiskScore (база 500 + 5 факторов, clamp 0…1000), Decision Engine с коридорами 650/520/450 и 4 встречными офферами, State Machine с ролями ИП/ООО, 60-дневный прогноз кассы, 5 триггеров радара, валидатор аномалий и Intent Parser на 4 класса.
- Frontend: три экрана (кабинет, заявка, рентген), Demo Control Bar, панели ДНК, прогноза, радара, поиска, PDF, офферов, ПЭП, P&L и Waterfall; сборка `npm run build` проходит.
- Документация сдачи: `docs/architecture-and-sla.md`, `docs/state-machine-ip-vs-ooo.md`, `docs/simplifications-registry.md`, `docs/bank-value-pdf-cash-forecast.md`, `THIRD_PARTY_NOTICES.md`; README переписан под запуск и демо.
- Тесты доведены до 35 passed: 5 эталонных профилей, ставки, Мультибанк 295 → 760, ПЭП 403/409, PDF 422, поиск ≤ 50 мс, идемпотентность сидера, платёж оффера в пределах MaxPayment.

### Changed
- README — продуктовый runbook для жюри (вместо только пакета правил агентов).
- Decision Engine принимает ставку ЦБ аргументом; при отсутствии аргумента использует `settings.cbr_key_rate`.
- Устаревший черновик API `routes_legacy_unused.py` удалён из репозитория (не был подключён).
- Контракт API зафиксирован по факту: 11 канонических эндпоинтов, 4 SPA-хелпера и `/health`; точные баллы, ставки и лимиты демо-сценариев сверены с `openapi.yaml`.
- Локальный запуск описан через SQLite + Uvicorn + Vite; Docker-контур оставлен на PostgreSQL 16.
- Исходные документы ТЗ и BRD (`.docx`) убраны из репозитория и добавлены в `.gitignore`: они остаются локально, но не попадают в коммиты.

### Fixed
- Убраны расхождения документации с кодом: число маршрутов, пороги коридоров, ставки 14,5/18,0/15,5/20,0%, лимит 300 000 ₽ на ручном разборе и причина Hard Stop «Бодрости Плюс».
- Лимит встречного оффера считается через приведённую стоимость аннуитета, поэтому платёж варианта не превышает MaxPayment.
- Повторная заявка после Мультибанка не застревает в ANOMALY, а оборот не удваивается; офферы инспектора для MANUAL_REVIEW больше не пустые.
- ПЭП только из `APPROVED` / `AWAITING_CEO_APPROVAL`: из `COUNTER_OFFER` без `accept-offer` — 409; кнопка ПЭП на фронте заблокирована до выбора оффера; бухгалтер ООО по-прежнему получает 403.
- Исправлена HTML-валидация суммы заявки: шаг 1000 ₽ вместо 10 000 ₽, из-за которого форма не отправлялась.
- Явно зафиксированы ограничения демо: симуляторы реестров, PDF без OCR, логическая подпись ПЭП без криптографии, опциональный ИИ и отсутствие аутентификации.
- OpenAPI: описание `verify-multibank` уточнено (фактор +90, пересчёт FCF/DSCR, +25% к лимиту, эталон 295→760).
