# Пользовательский путь Only_Alfa (демо BRD)

Документ описывает сквозной путь от входа до «деньги зачислены» для предпринимателя (ИП и ООО) и для пилота банка. Все расчёты и статусы — только с бэкенда.

## Роли

| Роль | Кто | Подпись ПЭП |
|------|-----|-------------|
| `IP_OWNER` | ИП, сам предприниматель | Да |
| `CEO_OWNER` | Генеральный директор ООО | Да |
| `ACCOUNTANT` | Бухгалтер ООО | Нет (только статус) |
| `UNDERWRITER` | Кредитный пилот банка | Нет |

## Предприниматель (бизнес-режим)

1. **Вход** — Demo Control Bar: компания (1 из 5 BRD), роль, ИНН при необходимости.
2. **Главная (К1)** — ДНК, касса, News-to-Action; проактивные подсказки ведут на `apply` / `decision` / `signing`.
3. **Заявка (К2)** — продукт, сумма, срок, залог; отправка → скоринг + Decision Engine + State Machine.
4. **Паспорт (К3)** — проверки, мультибанк при аномалии выручки.
5. **Решение (К4)** — `client_brief` (где / почему / что делать), письмо к офферу, 4 контр-оффера или одобрение; встречный запрос на другой продукт; переписка дублирует письмо.
6. **Сообщения** — лента `correspondence` из API (письма инспектора).
7. **Подпись (К5)** — только `CEO_OWNER` / `IP_OWNER`; бухгалтер видит статичный текст; после ПЭП — `FUNDED`, уведомление «деньги зачислены» всем ролям.
8. **Дозапрос** — загрузка документа → доменный пересчёт RiskScore → `score_changes` у клиента и пилота.

## Пилот банка (режим «Банк»)

1. **Клиенты / колокольчик** — входящие заявки, аномалии, документы.
2. **Стол разбора (bank-xray)** — вердикт по встречному запросу клиента, письмо к офферу, лента «система решила» (правило, кому, открытие/ответ клиента).
3. **Чаты** — синхронизация писем к офферам из заявки (`correspondence`).
4. **Действия** — одобрить / контр-оффер / дозапрос / решение по client-product-request.
5. **Проактив** — отправить или остановить исходящее действие до показа клиенту.

## 5 демо-профилей (контрольные баллы)

| Профиль | Балл | Типичный исход |
|---------|------|----------------|
| Смирнов | 815 | Одобрение |
| Ростерс | 610 | Встречные офферы |
| ТехноСтрой | 295→760 | Аномалия → мультибанк |
| Ковалев | 495 | Ручной разбор |
| Бодрость Плюс | 0 | Стоп-фактор |

## Критерий завершения

Предприниматель понимает статус без помощи, может запросить другой продукт, подписант получает уведомление на подпись, пилот за ~30 секунд видит встречный запрос и проактив системы.
